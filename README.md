# Étiquettes texte

Outil d'impression d'étiquettes Zebra 38 × 25 mm (1,5 × 1 in) à partir d'un texte libre.

https://etiquettes.waaplink.com

## Impression
- USB direct (WebUSB + ZPL, Chrome/Edge sur poste Windows)
- Zebra Browser Print (service local)
- Navigateur (papier 38 × 25 mm, marges Aucune, échelle 100 %)

Aucune dépendance externe : un seul fichier `index.html`.
